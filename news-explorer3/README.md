# stage-1-frontend-and-api2-NewsExplorer-finalproject

## Run locally

1. Copy `.env.example` to `.env`.
2. Replace `your_newsapi_key_here` with a NewsAPI key.
3. Run `npm install`, then `npm run dev`.

Cards appear after submitting a non-empty search. Restart the Vite server after changing `.env`.
